Hướng dẫn căn chỉnh lề chuẩn đồ án

📐 Cài đặt lề trang (Page Layout → Margins → Custom Margins)

Lề chuẩn đồ án:
• Lề trên (Top): 2.0 cm
• Lề dưới (Bottom): 2.0 cm
• Lề trái (Left): 3.0 cm (để đóng gáy)
• Lề phải (Right): 2.0 cm

🔤 Font chữ & Cỡ chữ

  • Font: Times New Roman
  • Cỡ chữ nội dung: 13pt (hoặc 12pt tuỳ trường)
  • Cỡ chữ tiêu đề chương: 14pt – 16pt, in đậm, in hoa
  • Cỡ chữ tiêu đề mục: 13pt – 14pt, in đậm

📏 Giãn dòng & Paragraph

  • Line spacing: 1.5 lines
  • Spacing Before: 0pt
  • Spacing After: 6pt
  • First line indent: 1.27 cm (0.5 inch)
  • Alignment: Justify (căn đều 2 bên)

📄 Đánh số trang

  • Trang bìa: không đánh số
  • Phần mở đầu (lời cảm ơn, mục lục): đánh số La Mã (i, ii, iii...)
  • Nội dung chính: đánh số Ả Rập (1, 2, 3...), bắt đầu từ trang 1
  • Vị trí: giữa cuối trang hoặc góc phải dưới

⚙️ Thao tác nhanh trong Word

1. File → Page Setup / Layout → Margins → Custom Margins
   → Nhập lề: Top 2cm, Bottom 2cm, Left 3cm, Right 2cm

2. Home → Font: Times New Roman, Size 13

3. Home → Paragraph:
   → Alignment: Justify
   → Line Spacing: 1.5
   → Special: First line = 1.27cm

4. Insert → Page Number → Bottom of Page
   → Format Page Numbers → Start at: 1
⚠️ Lưu ý: Kiểm tra lại quy định của trường/khoa trước khi áp dụng. Mỗi trường có thể có yêu cầu lề khác nhau.
Hướng dẫn trích nguồn chuẩn APA 7th

📖 Trích dẫn trong bài (In-text Citation)

1 tác giả: (Nguyễn, 2023) hoặc Nguyễn (2023) cho rằng...
2 tác giả: (Nguyễn & Trần, 2023)
3+ tác giả: (Nguyễn et al., 2023)
Tổ chức: (Bộ Công Thương, 2023)

📚 Danh mục tài liệu tham khảo

Sách:

Tác giả, A. B. (Năm). Tên sách (in nghiêng). Nhà xuất bản.

Ví dụ:
Nguyễn Văn A. (2022). Logistics và quản lý chuỗi cung ứng. NXB Đại học Kinh tế Quốc dân.

Bài báo khoa học:

Tác giả, A. B. (Năm). Tên bài báo. Tên tạp chí (in nghiêng), Tập(Số), Trang. https://doi.org/xxxxx

Ví dụ:
Trần Thị B. (2023). Thực trạng xuất khẩu vải thiều Việt Nam. 
Tạp chí Khoa học Thương mại, 15(2), 45-58. https://doi.org/10.1234/example

Website:

Tác giả/Tổ chức. (Năm, Tháng Ngày). Tên bài viết. Tên website. URL

Ví dụ:
Tổng cục Hải quan. (2024, Tháng 3 15). Thống kê xuất nhập khẩu 2023. 
https://www.customs.gov.vn/thongke2023

Báo cáo của tổ chức:

Tổ chức. (Năm). Tên báo cáo (in nghiêng) (Mã báo cáo nếu có). URL

Ví dụ:
Bộ Nông nghiệp & PTNT. (2023). Báo cáo xuất khẩu nông sản 2023. 
https://www.mard.gov.vn/report2023

🔧 Công cụ tạo trích dẫn tự động

  • Zotero (miễn phí) — quản lý nguồn + tự tạo APA
  • Mendeley — tích hợp Word plugin
  • Google Scholar → nhấn icon " → chọn APA
  • CitationMachine.net — web tạo citation nhanh
⚠️ Quy tắc quan trọng APA 7th:
• Sắp xếp TLTK theo thứ tự ABC tên tác giả
• Thụt dòng từ dòng thứ 2 trở đi (Hanging indent 1.27cm)
• DOI dạng URL: https://doi.org/xxxxx
• Không cần ghi "Truy cập ngày..." cho nguồn ổn định
• Tác giả Việt: ghi đủ họ tên, không viết tắt

Hướng dẫn chỉnh Headings & Mục lục tự động

🎯 Mục đích

Khi đã viết xong nội dung, cần gán Heading styles để Word tự tạo mục lục (Table of Contents). Điều này giúp:

  • Mục lục tự động cập nhật số trang
  • Điều hướng nhanh trong Navigation Pane
  • Trình bày chuyên nghiệp, đúng chuẩn

📋 Bước 1: Xác định cấu trúc Headings

Heading 1 → Tên chương (CHƯƠNG 1, CHƯƠNG 2...)
   Heading 2 → Mục lớn (1.1, 1.2, 2.1...)
      Heading 3 → Mục nhỏ (1.1.1, 1.1.2...)
         Heading 4 → Mục con (nếu cần)

Ví dụ:
CHƯƠNG 2: THỰC TRẠNG XUẤT KHẨU    → Heading 1
  2.1. Tổng quan thị trường          → Heading 2
    2.1.1. Sản lượng vải thiều VN    → Heading 3
    2.1.2. Kim ngạch xuất khẩu       → Heading 3
  2.2. Quy trình logistics hiện tại  → Heading 2

📋 Bước 2: Gán Heading trong Word

Cách 1 — Dùng Styles Gallery:
1. Bôi đen dòng tiêu đề cần gán
2. Tab Home → nhóm Styles
3. Click chọn "Heading 1" / "Heading 2" / "Heading 3"

Cách 2 — Dùng phím tắt:
• Ctrl + Alt + 1 → Heading 1
• Ctrl + Alt + 2 → Heading 2
• Ctrl + Alt + 3 → Heading 3

📋 Bước 3: Tuỳ chỉnh format Heading

Sau khi gán Heading, cần chỉnh lại format cho đúng chuẩn:

1. Click chuột phải vào style "Heading 1" → Modify
2. Chỉnh:
   - Font: Times New Roman
   - Size: 14pt (hoặc theo quy định)
   - Bold: Yes
   - Color: Automatic (đen)
   - Paragraph: 
     + Alignment: Center hoặc Left
     + Spacing Before: 12pt
     + Spacing After: 6pt
     + Line Spacing: 1.5

3. Tick ✅ "Automatically update"
4. Click OK

→ Làm tương tự cho Heading 2, 3

📋 Bước 4: Tạo Mục lục tự động

1. Đặt con trỏ ở trang muốn đặt mục lục
2. Tab References → Table of Contents
3. Chọn "Automatic Table 1" hoặc "Custom..."
4. Tuỳ chỉnh:
   - Show levels: 3 (hiện đến Heading 3)
   - Tab leader: dấu ......
   - Show page numbers: ✅

Cập nhật mục lục sau khi sửa nội dung:
→ Click vào mục lục → "Update Table" 
→ Chọn "Update entire table"
→ Hoặc nhấn: Ctrl + A → F9

📋 Bước 5: Bật Navigation Pane

View → tick ✅ Navigation Pane

→ Thanh bên trái sẽ hiện danh sách headings
→ Click vào heading để nhảy đến phần đó
→ Kéo thả để sắp xếp lại thứ tự
💡 Mẹo: Nếu đồ án đã viết xong mà chưa gán Heading, hãy dùng Find & Replace (Ctrl+H) với Format → Style để tìm nhanh các dòng cần gán Heading.
